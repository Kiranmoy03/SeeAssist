# Google Colab

This folder is for the SeeAssist development notebook and runtime-recovery notes.

Current backend stack:
- LFM2.5-VL-3B for VQA and scene description
- YOLO26n for object detection/counting
- PP-OCRv6 Small for OCR
- Gradio development API for Android integration

The Colab backend is temporary development infrastructure and is not intended to be required by the final zero-recurring-cost prototype.
